California Trout Fishing Guide

Website Planning Document

Site Name

California Trout Fishing Guide

I chose this name because it clearly describes the purpose of the website. Visitors will immediately know the site focuses on trout fishing in California.

Site Purpose

The purpose of this website is to provide beginner and intermediate anglers with information about trout fishing in California. Visitors will learn about fishing locations, gear, and basic fishing techniques.

Scenarios

  • Where are the best trout fishing lakes and rivers in California?
  • What fishing rod, reel, and lures should I buy for trout fishing?

Color Schema

The colors chosen will reflect water and vegetation with blue and green. Blue will be used for the header and footer. The green will be used on each section and the header for each section.
